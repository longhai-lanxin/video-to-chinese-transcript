# video-to-chinese-transcript

把本地视频/音频转写成中文文字稿（faster-whisper），并处理「HuggingFace 下载被墙/超时」的环境。触发：视频转文字、语音转写、ASR、视频生成学案/逐句分析、课程视频提取知识点。

## Install

```bash
git clone https://github.com/longhai-lanxin/video-to-chinese-transcript.git ~/.workbuddy/skills/video-to-chinese-transcript
```

Or copy the whole folder into your skills directory.
